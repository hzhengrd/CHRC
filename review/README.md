# Systematic-review coding data

This directory will hold the coding data of the systematic review described in Section 3 of the manuscript.

Planned files:

- `codebook.md` — the coding protocol: operational definitions of `captured` / `notCaptured` / `notReported`, the 17 H/R/T/E categories, and the nine data-instantiation properties.
- `resources-coding.csv` — the per-resource coding table for all 170 consolidated resources (machine-readable version of Supplementary Table S4).
- `excluded-studies.csv` — the full-text studies excluded at assessment, with reasons (PRISMA exclusion list).

These files are produced from the review's coding spreadsheet and will be added once finalized.
